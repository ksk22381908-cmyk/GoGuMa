# 작은 고구마밭

모바일 브라우저용 고구마 수집·산책·랜덤 카드 디펜스 프로토타입입니다.

화면 전체는 외부 폰트나 이미지 없이 동작하는 8비트 픽셀 스타일입니다. UI 패널, 버튼, 캐릭터 초상화와 전투 캐릭터, 지도 테두리와 효과에 단단한 픽셀 형태와 제한된 색상 팔레트를 적용했습니다.

## 실행

Node.js가 설치된 환경에서 `node serve.cjs`를 실행하고 http://127.0.0.1:4173 을 엽니다. 또는 같은 폴더의 파일을 유지한 채 index.html을 브라우저로 엽니다. 주소가 바뀌면 브라우저 저장 공간도 달라집니다.

## 플레이

- 밭: 물 5번 → 랜덤 고구마 수확. 30종의 확률은 각각 1/30입니다.
- 도감: 수확한 캐릭터를 선택합니다. 같은 캐릭터도 보유 수량이 쌓입니다.
- 마을: 지도 터치·방향 버튼·WASD/방향키로 산책합니다.
- 방어전: 선택한 캐릭터로 출전합니다. 드래그 또는 방향키로 이동하며 자동 공격합니다.
- 1~5웨이브는 각각 12초 뒤 카드 3장 중 1장을 선택합니다. 적은 다음 웨이브로 이어집니다.
- 6웨이브에는 보스가 등장합니다. 생성 종료 후 남은 적과 보스를 모두 처치하면 승리합니다.
- 적이 45마리 이상 쌓이면 패배합니다. 접촉 피해는 없습니다.
- 승리 보상은 랜덤 고구마 1마리이며 도감에 자동 저장됩니다. 전투 강화는 매 출전 초기화됩니다.
- 메뉴 변경·창 비활성화 시 전투가 일시정지됩니다. 새로고침하면 진행 중인 전투는 초기화되며 수집 내역은 유지됩니다.

## 벤치마킹

Hailot의 캐릭터별 능력, 랜덤 카드 강화, 조합, 웨이브 구조를 참고했습니다. 기존 게임의 명칭·이미지·카드 문구 대신 고구마와 정원 테마의 독자 콘텐츠를 사용합니다.

- 개발사 소개: https://marc-official.com/54
- 개발사 웨이브·카드 패치 설명: https://marc-official.com/58
- 공식 App Store: https://apps.apple.com/kr/app/id1660366590
- 요청된 나무위키 링크는 접근 오류로 본문을 확인하지 못했습니다.

현재 범위는 30종 고유 공격, 12개 카드, 6웨이브, 보스 1종입니다. 모바일 앱 패키징 및 배포는 포함하지 않습니다.

## 공격과 지형 업데이트

- 캐릭터마다 공격 형태, 대상 선택, 발사 간격, 사거리, 지속 효과가 다릅니다. 출전 준비와 전투 중에 고유 공격 설명을 표시합니다.
- 바위는 플레이어·해충 이동과 직선·관통·연쇄·폭발 피해를 차단합니다. 관통은 적을 통과하며 바위는 통과하지 않습니다.
- 곡사 공격은 바위 너머 지정된 지점에 0.5초 후 떨어집니다. 착탄 후 범위 피해는 바위에 차단됩니다.
- 연못은 이동을 막고 공격은 통과합니다. 수풀 안에서는 플레이어와 해충 이동 속도가 45% 감소합니다.
- 이동은 장애물에 부딪히면 멈추거나 벽을 따라 미끄러집니다. 자동 경로 탐색은 없으므로 직접 우회합니다.
- 덫·지속 지대·회전 꽃잎은 위치 선정이 중요하며, 강화 카드로 공격 대상·폭·위력이 공격 방식에 맞게 확장됩니다.
